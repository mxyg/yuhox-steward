## 平台限制总账（对外必须如实的四条）

1. **iOS / iPadOS 出局。** 苹果不给第三方任何一项本矩阵的能力，且要 $99/年开发者账号。任何声称能"清理 iPhone 垃圾""让 iPhone 永不锁屏"的应用都在骗人。安卓走 ADB，从电脑管，不做手机端 App。
2. **不签名。** 公司不出钱买证书，所以 macOS 首次打开要右键→打开，Windows 会弹 SmartScreen「未知发布者」。这一步必须写在下载页第一屏，不许藏在 FAQ 里。
   现状已实测：现有交付包（昱弘控境 0.5.1 的 arm64 dmg）`Signature=adhoc`、`TeamIdentifier=not set`，`spctl -a -t install` 判 rejected —— 也就是"要右键打开"不是推测，是已经发生的事。这条同时封掉了 J 组的实时拦流量。
3. **macOS 的驱动修复、别人窗口置顶、按进程流量** 这三项受平台限制，见各表备注。
4. **三件我们主动不承诺的事**：病毒查杀（开源库对国产流氓软件无力，做半吊子比不做更糟）、
   误删文件恢复（SSD 开了 TRIM 就基本无效）、以及任何"提速 X%"式的表述（没有可复现口径）。
   这三条不是平台挡着，是我们自己划的线 —— 做不到可靠的东西写进产品页，第一次被用户拆穿就全完了。

## 「一键优化」的口径红线

这类按钮是管家的门面，一定做。但数字必须是真的，五条写死：

1. **只印实测差值。** 释放前后的可用内存 / 内存压力真实差值，取不到就不显示数字，不许估。
2. **不许出现「提速 X%」。** 没有可复现口径支撑的数，写出去就是骗人，而且是我们自己无法辩护的那种骗人。
3. **杀掉 ≠ 变快。** 现代系统本来就按内存压力自动回收，杀应用腾出来的多半是缓存。
   老机器越来越卡的真实来源是**常驻启动项过多、磁盘接近满、热降频、泄漏不放的进程**，
   所以「卡顿体检」必须给这四项的实测数字和各自对应的处置入口，一键优化只是其中一项，不是全部。
4. **两档并排。** 优雅退出（等它自己收）和当场强杀（立刻断）同时给，不许只留前者让人等超时。
5. **要解释回弹。** 释放掉的内存会在几分钟内被系统缓存重新占满，这是正常的；
   界面不写清这一点，用户会以为"没用，又卡回去了"，然后再也不点。
