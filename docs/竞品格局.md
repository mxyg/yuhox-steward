## 三条结论

**1. 清理、卸载、菜单栏监控是红海，不许当卖点。**
Mole 6.8 万 star 且今天还在提交，Stats 4.2 万。这两块我们做到"有、且跨平台"即可，
宣传上不许把它们放在第一屏。

**2. 菜单栏图标整理是空档，不是被占死了。**
Ice 停更一年、release 近两年没动，未关 issue 里 2026-09-14 还有人问
「能不能出个 Tahoe 稳定版」，另有 macOS 26 下布局失效、图标残留 dock 的 bug。
**停更 + 新系统搞坏 = 窗口期**，所以这一项从 S5 提到 S2。

**3. 「合盖 + 无头 + 跑完即停」这个组合，加上跨平台，没人做。**
搜 `cross platform pc manager cleanup` 零结果；上面六个项目全部 macOS 单平台。
KeepingYouAwake 只做常亮，Crisp 只做显示器，都不碰休眠策略与任务监控。
**这就是 S1 的全部内容，也是这个产品能存在的理由。**

## 两处要记住的旁证

- **Pearcleaner 用的是 fair-code（源码公开 + 商用限制）**，1.4 万 star、活跃。
  说明我们选 PolyForm Noncommercial 这条路在 macOS 工具上是走得通、也有人认的。
- **Crisp 在 README 里自己写明**：项目的主要运行成本就是 **$99/年苹果开发者账号**，
  用来签名和公证让安装不报警告，目前靠用户捐赠覆盖。
  我们按老板的决定不签名，但这条记在案上：star 攒起来之后，这笔钱可以众筹。
  代价对比很清楚 —— Crisp 每个 release 都是 signed + notarized，双击就装；我们不是。
