# 昱弘设备管家 Yuhox Steward

**人不在的时候，设备照常干活；设备本身，替你管干净。**

一台 Mac 或者一台安卓，装上它之后：合上盖子任务继续跑、算完了自己睡、
孤儿进程和残留垃圾有人收、菜单栏不再挤成一排。

官网 <https://steward.yuhox.com>　技术支持 support@yuhox.com　辽宁昱弘智能科技有限公司

## 它管哪几件事

十组能力，逐条标注每个平台做到 / 需提权 / 做不到 —— **真源是 `docs/能力矩阵.md`**，
官网功能页和界面文案只能从那张表抄，表里写 `✗` 的不许出现在任何对外文案里。

| | 组 | 一句话 |
|---|---|---|
| A | 电源与运行状态 | 合盖不睡、无头也能算、跑完自己停、电池与温度 |
| B | 进程与启动项 | 进程树、孤儿回收、启动项与后台常驻审计、勾选活跃应用处置 |
| C | 存储与清理 | 空间地图、缓存日志、卸载残留、开发垃圾、本地快照 |
| D | 卸载与应用管理 | 批量卸载、装前装后快照追残留、多版本清理 |
| E | 网络 | 实时流量、按进程流量、连接表、端口冲突、按症状排障 |
| F | 诊断与修复 | 卡顿归因、系统文件与磁盘体检、运行库缺失修复、驱动修复（Windows） |
| G | 窗口与桌面 | 悬浮性能球、窗口置顶与分屏、菜单栏图标整理、剪贴板与快捷键 |
| H | 软件中心 | 搜索安装、版本检查、批量升级（转调系统包管理器，不自建源） |
| I | 硬件体检 | 系统信息、SMART、坏点与外设测试、耗电排行、唤醒诊断 |
| J | 安全与流氓拦截 | 弹窗广告与流氓特征、主页劫持检测、自启来源审计、签名异常 |

三件我们**主动不承诺**的事：病毒查杀、误删文件恢复、任何「提速 X%」的说法。
理由写在能力矩阵末尾，一句话版本是：做不到可靠的东西放进产品页，第一次被用户拆穿就全完了。

## 各平台做到什么程度（这一点不藏）

不同设备能给第三方软件的权限差得非常远，所以分开说清楚：

| 能力 | macOS | 安卓 | iOS / iPadOS |
|---|---|---|---|
| 防自动休眠 | 可以，不需提权 | 可以（ADB） | 只能引导你去设置里改 |
| 合盖不休眠 | 需要管理员权限 | — | — |
| 无头渲染 | 需要虚拟显示器 | — | 不适用 |
| 任务完成后动作 | 可以 | 可以 | 不可以 |
| 看进程 / 杀进程 | 本人进程可以，系统的需提权 | 可以（ADB） | 不可以 |
| 卸载应用与残留 | 可以 | 可以 | 不可以 |
| 清理垃圾 | 可以 | 部分 | 不可以 |
| 整理菜单栏图标 | 可以 | 不适用 | 不适用 |

**iOS 上不做到的事，我们不会在产品页上写。** 苹果没有给第三方这些口子，
任何声称能"清理 iPhone 垃圾""让 iPhone 永不锁屏"的应用都在骗人。

## 许可与商用

**源码公开，非商业使用免费；商业使用需要购买授权。**

许可证是 [PolyForm Noncommercial 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0)：
源码公开，任何人可读、可改、可自用，但**任何商业用途需要另行取得授权**。

说在前面的几件事：

- **软件里没有任何授权机制。** 不用激活、不绑机、不校验、不到期。
  免费用和买了授权用，跑的是**完全相同的一份程序**。
- 购买商业授权得到的是一份**纸面凭证**（授权书 PDF + 发票），和软件运行无关，
  给需要合规入账、投标、审计的单位用。
- **按天购买，天数任意填**，不设套餐，也不设最低起购。

同一个许可体系下的另一个公开源码产品是 [昱弘网通 NetKit](https://github.com/mxyg/netkit)。
